Start here

Three steps. No install scripts.

  1. Download & unzip

    Get the ZIP above and open it in Finder. You’ll get a folder called Session Limits.

  2. Import into Raycast

    Search for Import Extension in Raycast, then select that Session Limits folder.

  3. Check your limits

    Run Show Session Limits. Open any quota row to see the gauge and reset details.

Connect what you use.

Codex

Already signed in to Codex on this Mac? Session Limits reads quotas through the official Codex CLI.

Claude Code

Choose Connect Claude Code, then use Claude Code to update your reading. Uses its official status line quota data and preserves your existing status line. Requires Claude Code 2.1.251+ and a Pro or Max plan.

Your own provider

Supply a local JSON snapshot using the documented format. The same quota view works with your data.

Small by design.

No backend, no analytics, and no account with us. Claude’s connector reads quota data, without requesting your tokens or Keychain access.
