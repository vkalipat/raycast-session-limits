Good questions

Good to know.

How do I connect my providers?

Codex uses your existing CLI sign-in. For Claude Code, choose Connect Claude Code, then use Claude to update your reading. Requires Claude Code 2.1.251+ and Pro or Max; your existing status line is preserved.

Is it in the Raycast Store?

The Store submission is awaiting review. Install the GitHub download with Raycast’s Import Extension command today.

Can I add another provider?

Yes — use the local JSON format, or request an integration.
